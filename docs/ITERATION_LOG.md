资料页采用微信原生头像选择和昵称输入控件，不调用已废弃的完整用户资料接口；可选手机号仅在用户主动点击后通过云函数处理短时动态凭证，持久化内容限制为绑定状态、后四位掩码和时间。头像、昵称和手机号均可跳过，不影响餐单核心功能。

AI task schema v3 增加每次生成的同意协议版本；生成确认页默认不勾选，修改发送内容撤销旧同意，客户端与云函数状态握手共同要求协议 v2。控制文档只记录版本和服务端时间，不记录用户输入，也不复用为下一次同意。无同意旧任务在重放、读取、领取、worker 回写和到期维护路径以 `AI_DATA_CONSENT_REQUIRED` 失败关闭；具有同意版本但缺少计划摘要的旧任务仍以冲突关闭。AI 内容仅在 `source: ai` 时显示“AI生成”标识。

任务 schema 门禁覆盖 status、current、claim、settle、cancel、replay、advance、终态压缩和分片维护。缺失、字符串、0 等非法版本返回 `AI_TASK_VERSION_INVALID`，高于 v3 的未来版本返回 `AI_TASK_SCHEMA_VERSION_UNSUPPORTED`；拒绝路径不调用上游 AI，不写任务、控制、分片或用户状态。维护函数对不支持版本只跳过，等待兼容代码处理，不能把未来任务降级为当前结构。
