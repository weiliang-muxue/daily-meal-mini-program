## 引用身份

| 类型 | 当前或历史引用 | 是否可移动 | 用途 |
| --- | --- | --- | --- |
| Branch | `refs/heads/v0.2.0` | 是 | 当前 `0.2.0` 发布候选与审核准备 |
| Tag | `refs/tags/v0.1.0` | 否 | `2026-08-25` 首个原生小程序追溯源码基线 |

`main` 只作为默认分支迁移时的临时过渡。查看或操作引用时必须写明 Branch 或 Tag；自动化命令使用完整 ref，避免同名歧义。
