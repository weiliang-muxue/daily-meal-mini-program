# 隐私与用户信息说明

## 对用户的简明说明

“每天怎么吃”使用微信登录识别你的账号，以便在换手机或重新进入时恢复计划。仅有邀请码的成员可以使用。我们保存你的餐食调整、星期和晚餐模式、采购勾选、提醒设置、体重、运动打卡、备注，以及你主动选择的头像和体重照片。

- 不会自动获取完整微信资料。
- 昵称使用 `input type="nickname"` 由用户填写。
- 头像使用 `button open-type="chooseAvatar"` 由用户主动选择；永久文件私有保存，界面只接收短期预览 URL。
- 用户可以不填写头像昵称，仍可使用饮食计划。
- 体重照片只在用户主动选择相册或相机后上传，永久文件默认不允许客户端直接读取，查看时由云函数返回短期地址。
- 3–4 位成员的数据以服务端解析的微信身份隔离，成员不能选择或查询其他人的记录。
- AppSecret、`session_key`、`openid`、`unionid` 不进入小程序前端。
- 健康提醒是执行辅助，不构成诊断、处方或治疗建议。

## 平台隐私配置建议

在微信公众平台“小程序用户隐私保护指引”中声明：

1. 头像：用于显示用户主动设置的个人头像。
2. 昵称：用于显示用户主动设置的称呼。
3. 用户操作记录：用于同步星期、晚餐模式、采购清单和提醒设置。

当前版本不采集手机号、定位、通讯录或相册列表。运动类型、时长、强度和体重由用户主动记录，不自动读取微信运动或医疗检查结果。

## 数据删除

“我的”页提供“清空我的私人数据”，二次确认后永久删除当前用户的档案、饮食状态、健康记录、头像与体重照片，但保留邀请成员资格，方便重新开始。其他成员数据不受影响。
