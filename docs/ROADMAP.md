# 发布后路线图

首版发布门槛仍是：用户先选择饮食目标、运动计划、忌口与健康约束，再由云函数调用 AI 生成并确认个人食谱；完成数据隔离、持久化、测试、部署和发布。

以下能力仅记录为第二阶段，首版不接入：

1. 在用户主动授权后获取当前位置，拒绝授权时保持现有采购清单可用。
2. 查询附近超市并展示距离、营业信息和可用路线。
3. 使用微信地图能力调起路线规划或导航，不在小程序中自行实现导航引擎。
4. 调研有明确授权、稳定更新和可核验来源的商超/生鲜价格 API。
5. 仅展示来自可靠数据源并标注更新时间的价格；AI 不生成或猜测实时蔬菜价格。
6. 补充位置权限用途说明、最小化采集、短期缓存、删除机制和隐私保护指引。

进入第二阶段前需重新核对微信位置接口、隐私合规、服务类目、合法域名和第三方数据源条款。
